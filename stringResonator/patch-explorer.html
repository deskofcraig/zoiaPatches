Version 3 corrects fundamental module errors in v1 and v2 discovered against the official Empress Module Index. All modules now use verified ZOIA module names and exact block counts.
Critical corrections from v1/v2
ERROR CORRECTEDResonator module does not exist in ZOIA
The "Resonator" module was used in v1 and v2 but is not in the official firmware 5 module index. Replaced with Delay Line + VCA feedback loop (comb filter / Karplus-Strong resonator). Each voice = 1 Delay Line (3 blocks) + 1 VCA (3 blocks). FEEDBACK knob controls VCA level = controls resonance decay time.
ERROR CORRECTEDPitch Detector has no gate output
Official spec: Pitch Detector has exactly 2 blocks — audio in (block 1) and pitch out (block 2). No gate output exists. v1/v2 connected a nonexistent "gate_out" block to S&H and ADSR. Fixed: Env Follower (block 1: audio in, block 2: CV out) → Comparator (block 1: positive, block 2: negative/threshold, block 3: CV out) generates gate. This saves 9.76% CPU vs using Onset Detector.
ERROR CORRECTEDCV Adder module does not exist in ZOIA
No "CV Adder" module in ZOIA. Replaced with CV Mixer (5 blocks: cv in 1, cv in 2, atten 1, atten 2, cv output). To sum two CVs: set both attenuators to 1.0. DSP = 0.30%.
ERROR CORRECTEDVCA block names were wrong
Official VCA blocks: audio in 1 (1), audio in 2* (2), level control (3), audio out 1 (4), audio out 2* (5). We previously labelled block 3 as "gain_cv" — correct name is "level control". This block accepts CV input for gain automation.
ERROR CORRECTEDChorus CPU was severely underestimated
Official Chorus DSP: 6–10% (not 3% as estimated). Removed from patch. Stereo width now handled by Audio Balance stereo (0.8% DSP) with Delay Lines panned hard L/R for Haas effect.
ERROR CORRECTEDAll grid block counts were 1 block — now corrected
Every module in v1/v2 was shown as 1 block in grids. Official block counts: VCA=3, SV Filter=4, Delay Line=3, ADSR=6, S&H=3, Tone Control=9, Reverb Lite=5, CV Mixer=5, Pitch Detector=2, Env Follower=2, Comparator=3, Value=2, Audio Balance=7. SVG grids now show actual footprint.
v3 total CPU: ~32% (vs ~68% in v2). The removal of the Chorus (was 6-10%) and replacement of Resonator modules (was 9% each ×4 = 36%) with Delay Line+VCA comb filters (2%+0.3% each) is the primary saving. Env Follower+Comparator (2.54%) replaces Onset Detector (12.3%) saving another 9.76%.

What is this patch?

Sympathetic Strings Resonator v3 adds the resonant character of a piano’s undamped strings to your guitar using verified ZOIA modules. When you play a note, an Env Follower detects the signal, a Comparator generates a gate, and the Pitch Detector captures the fundamental frequency. Three Delay Line + VCA feedback comb filters resonate at the fundamental, octave, and fifth, with two additional short Haas delays providing stereo width.

The resonators use a Karplus-Strong comb filter approach: each Delay Line’s output feeds back into its own input through a VCA. The FEEDBACK knob controls VCA level — higher feedback = longer sustain. Pitch CV from the Pitch Detector modulates the delay times to approximate tuning.

Key features

  • Env Follower + Comparator gate detection (saves 9.76% vs Onset Detector)
  • Pitch Detector with CV Rectify for delay-time pitch control
  • 3 Delay Line + VCA comb filter resonators: fundamental, octave (+12st), fifth (+7st)
  • 2 Haas delay lines (L/R) for stereo width
  • SV Filter for post-resonator dampening (felt simulation)
  • Tone Control (9 blocks) for piano body coloration
  • Reverb Lite (Empress CPU-friendly reverb) for acoustic space
  • All modules verified against official Empress Module Index (firmware 5)

Firmware requirement

Minimum: firmware 2.0+ (all modules present from v2). Recommended: firmware 5.0 for UI Button 15-colour extended range. All modules in this patch (Audio In/Out, VCA, SV Filter, Delay Line, Pitch Detector, Env Follower, Comparator, Sample & Hold, ADSR, CV Mixer, CV Rectify, Value, Stompswitch, Tone Control, Reverb Lite, Audio Balance) are confirmed available in firmware 5.x per the official module index provided.

Architecture change from v2

The resonator voices are now built from Delay Lines with VCA feedback rather than a "Resonator" module that does not exist in ZOIA. The pitch tracking is approximate — the Pitch Detector’s V/Oct CV is scaled (via connection strength) into the Delay Line’s linear delay time range. This gives musically useful pitch-approximate resonance, similar to how analog sympathetic strings work.

First time: Start with FEEDBACK at 60%. Play a single note and raise slowly until you hear the resonant bloom. If it self-oscillates, lower FEEDBACK. SENSITIVITY controls how easily the resonators trigger — lower it if they trigger on noise.
