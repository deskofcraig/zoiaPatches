What is this patch?

Sympathetic Strings Resonator v3 adds the resonant character of a piano’s undamped strings to guitar using only verified ZOIA modules. When you play, an Env Follower detects the signal, a Comparator generates a gate, and the Pitch Detector captures pitch. Three Delay Line + VCA feedback comb filters resonate at the fundamental, octave, and fifth. Two Haas delays create stereo width.

The resonators use a Karplus-Strong comb filter: Delay Line output feeds back into its own input through a VCA. FEEDBACK knob controls VCA level — higher = longer sustain. Pitch CV modulates delay times for approximate pitch tracking.

Key features

  • Env Follower + Comparator gate detection — 2.54% CPU vs Onset Detector 12.3%
  • 3× Delay Line + VCA comb filter voices: fundamental, octave, fifth
  • 2× Haas delay lines L/R for stereo width
  • SV Filter dampening (felt simulation) · Tone Control body EQ · Reverb Lite
  • All modules verified against official Empress Module Index firmware 5
  • ~32% CPU · ~63% headroom below 95% ceiling

Firmware

Minimum 2.0. Recommended 5.0 (15-colour UI Button). Modules: Audio In/Out, VCA, SV Filter, Delay Line, Pitch Detector, Env Follower, Comparator, Sample & Hold, ADSR, CV Mixer, CV Rectify, Value, Stompswitch, Tone Control, Reverb Lite, Audio Balance.

First time: Set FEEDBACK 60%, play a note, raise slowly until resonance blooms. Self-oscillating? Lower FEEDBACK. SENSITIVITY adjusts trigger threshold.
