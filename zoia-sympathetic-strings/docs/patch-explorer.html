What is this patch?

Sympathetic Strings Resonator v3 adds the resonant character of a piano’s undamped strings to guitar using only verified ZOIA modules. When you play, an Env Follower detects the signal, a Comparator generates a gate, and the Pitch Detector captures pitch. Three Delay Line + VCA feedback comb filters resonate at the fundamental, octave, and fifth. Two Haas delays create stereo width.

The resonators use a Karplus-Strong comb filter: each Delay Line’s output feeds back into its own input through a VCA. The FEEDBACK knob controls VCA level — higher = longer sustain. Pitch CV modulates delay times for approximate pitch tracking.

Key features

  • Env Follower + Comparator gate detection — saves 9.76% CPU vs Onset Detector (12.3%)
  • Pitch Detector with CV Rectify for pitch-to-delay-time control
  • 3× Delay Line + VCA comb filter voices: fundamental, octave, fifth
  • 2× Haas delay lines panned L/R for stereo width
  • SV Filter dampening (felt simulation)
  • Tone Control body EQ (9 blocks) + Reverb Lite (6–7%)
  • All modules verified against official Empress Module Index firmware 5
  • ~32% CPU — ~63% headroom below 95% ceiling

Firmware requirements

Minimum: 2.0. Recommended: 5.0 (for 15-colour UI Button). Modules used: Audio In/Out, VCA, SV Filter, Delay Line, Pitch Detector, Env Follower, Comparator, Sample & Hold, ADSR, CV Mixer, CV Rectify, Value, Stompswitch, Tone Control, Reverb Lite, Audio Balance.

First time: Set FEEDBACK to 60%. Play a single note and slowly raise until you hear the resonant bloom. If it self-oscillates, lower FEEDBACK. SENSITIVITY adjusts the trigger threshold.
All DSP from official Empress Module Index firmware 5. ~32% total vs ~68% (v2) and ~83–109% (v1).
