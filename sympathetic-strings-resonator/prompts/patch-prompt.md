# ZOIA Sympathetic Strings Resonator v3 — Patch Build Prompt

**Version:** 3.0 · **Firmware minimum:** 2.0 · **Firmware recommended:** 5.0
**CPU:** ~32% estimated (~63% headroom to 95% ceiling)
**Hardware:** ZOIA + ZEBU · **Input:** Mono · **Output:** Stereo

---

## Patch Description

A pitch-tracking sympathetic string resonator that adds grand piano resonance
to guitar. Three Delay Line + VCA feedback comb filters (Karplus-Strong) are
excited by the guitar signal and approximately tuned to the detected pitch.
Two Haas delay lines create stereo width. Dry guitar and wet resonators blend
through an Audio Balance stereo mix bus.

All modules verified against the official Empress ZOIA Module Index (firmware 5).
See `patch/module-index.csv` for the complete reference.

---

## Critical Module Corrections (vs earlier versions)

These modules do NOT exist in ZOIA and must not be used:
- **Resonator** — does not exist. Use Delay Line + VCA feedback (comb filter).
- **CV Adder** — does not exist. Use CV Mixer with attenuators set to 1.0.

These blocks do NOT exist:
- **Pitch Detector gate output** — Pitch Detector has only 2 blocks: audio in
  (block 1) and pitch out (block 2). Gate is generated by Env Follower +
  Comparator (saves 9.76% CPU vs Onset Detector at 12.3%).
- **VCA gain_cv** — VCA block 3 is called "level control", not "gain_cv".

## Complete Module List with Official Block Names

### P1 — UI Controls (21 of 40 blocks)

All modules output CV only. No audio processing on this page.

**Value modules — 2 blocks each:**
- Value [PITCH] — block 2 CV output → P3 CV Mixer cv in 2 (block 2)
- Value [FEEDBACK] — block 2 → P4 VCA V1/V2/V3 level control (block 3) at 100/80/55%
- Value [SPREAD] — block 2 → P4 Delay L/R delay time (block 2)
- Value [DAMPENING] — block 2 → P4 SV Filter [DAMPENING] frequency (block 2)
- Value [SENSITIVITY] — block 2 → P3 Comparator CV negative input (block 2)
- Value [PIANO SIZE] — block 2 → P5 Tone Control low shelf (block 3) + mid freq 1 (block 5)
- Value [REVERB LVL] — block 2 → P5 VCA [REVERB SEND] level control (block 3)
- Value [WET VOL] — block 2 → P2 VCA [WET VCA] level control (block 3)
- Value [DRY VOL] — block 2 → P2 VCA [DRY VCA] level control (block 3)

**Stompswitch modules — 1 block each:**
- Stompswitch [BYPASS] — latching — block 1 → P2 VCA [WET VCA] level control override to 0
- Stompswitch [PITCH HOLD] — latching — block 1 → P3 Sample and Hold trigger (block 2)
- Stompswitch [DECAY KILL] — momentary — block 1 → P4 VCA V1/V2/V3 level control at strength 0

*ZEBU: map BYPASS → CV In 1, PITCH HOLD → CV In 2, DECAY KILL → CV In 3*

### P2 — I/O + Mix Bus (18 of 40 blocks)

- Audio Input [GUITAR IN] — 2 blocks — pedal input L → P3 Soft Limiter, Pitch Detector, Env Follower, Dry VCA (all 100%)
- VCA [WET VCA] — 3 blocks — level control (block 3) ← Value [WET VOL] / Bypass override
- VCA [DRY VCA] — 3 blocks — level control (block 3) ← Value [DRY VOL]
- Audio Balance [STEREO MIX BUS] — 7 blocks stereo — in1L ← Wet VCA, in2L ← Dry VCA, in1R ← Reverb Lite output R
- Audio Output [STEREO OUT] — 3 blocks — ← Audio Balance outL + outR

### P3 — Pitch Tracking (25 of 40 blocks)

- SV Filter [SOFT LIMITER] — 4 blocks — frequency: 3kHz fixed, resonance: 0
  → P4 Delay V1 (100%), V2 (80%), V3 (55%), SPREAD L/R (90%)
- Pitch Detector [TRACKER] — **2 blocks only, NO gate output**
  block 2 pitch out → CV Mixer cv in 1 + Sample and Hold CV input (block 1)
- Env Follower [GATE DETECT] — 2 blocks — rise/fall OFF
  block 2 CV output → Comparator CV positive input (block 1)
- Comparator [GATE GEN] — 3 blocks
  block 1 ← Env Follower / block 2 ← Value [SENSITIVITY] / block 3 → S&H trigger + ADSR cv input
- Sample and Hold [PITCH HOLD] — 3 blocks
  block 1 ← CV Mixer cv output / block 2 ← Comparator + Stompswitch [PITCH HOLD]
  block 3 CV output → CV Rectify CV input (block 1)
- CV Mixer [PITCH OFFSET] — 5 blocks — atten 1 = 1.0, atten 2 = 1.0 (sums CVs)
  block 1 ← Pitch Detector / block 2 ← Value [PITCH] / block 5 → Sample and Hold
- ADSR [GATE ENVELOPE] — 6 blocks — A: 8ms, D: 30ms, S: 100%, R: 60ms
  block 10 cv output → P4 VCA V1/V2/V3 level control (block 3) at 100/80/55%
- CV Rectify [PITCH POS] — 2 blocks
  block 2 → P4 Delay V1 delay time at 6%, V2 at 3%, V3 at 4% connection strength

### P4 — Resonator Bank (28 of 40 blocks)

*Comb filter principle: Delay audio out → VCA audio in → VCA audio out → Delay audio in (feedback loop). FEEDBACK knob sets VCA level control. Pitch CV sets delay time.*

- Delay Line [V1 FUNDAMENTAL] — 3 blocks — max time: 100ms, base delay: 2.3ms
  block 1 audio in ← Soft Limiter (100%) + VCA V1 FEEDBACK (75% feedback)
  block 2 delay time ← CV Rectify at 6% strength
  block 3 audio out → VCA V1 FEEDBACK + SV Filter DAMPENING
- VCA [V1 FEEDBACK] — 3 blocks
  level control (block 3) ← ADSR (100%) + FEEDBACK knob (100%) + Decay Kill override (0)
  audio out (block 4) → Delay V1 audio in at 75% (feedback)

- Delay Line [V2 OCTAVE] — 3 blocks — base delay: 1.1ms (~octave)
  block 2 ← CV Rectify at 3% / block 3 → VCA V2 FEEDBACK + SV Filter DAMPENING
- VCA [V2 FEEDBACK] — 3 blocks — level control ← ADSR at 80% + FEEDBACK at 80%

- Delay Line [V3 FIFTH] — 3 blocks — base delay: 1.5ms (~fifth)
  block 2 ← CV Rectify at 4% / block 3 → VCA V3 FEEDBACK + SV Filter DAMPENING
- VCA [V3 FEEDBACK] — 3 blocks — level control ← ADSR at 55% + FEEDBACK at 55%

- Delay Line [SPREAD L] — 3 blocks — block 2 delay time ← Value [SPREAD] (9ms)
- Delay Line [SPREAD R] — 3 blocks — block 2 delay time ← Value [SPREAD] (11ms, +2ms offset)

- SV Filter [STRING DAMPENING] — 4 blocks — 12dB/oct LPF
  block 1 audio in ← all 5 Delay Line outputs
  block 2 frequency ← Value [DAMPENING] (3500Hz)
  block 4 lowpass output → P5 Tone Control aud in L (block 1)

### P5 — Piano Body + Reverb (20 of 40 blocks)

- Tone Control [BODY EQ] — 9 blocks
  aud in L (block 1) ← SV Filter DAMPENING lowpass output
  low shelf (block 3) ← Value [PIANO SIZE] (+2.2dB at 55%)
  mid gain 1 (block 4): +3dB fixed
  mid freq 1 (block 5) ← Value [PIANO SIZE] (280Hz at 55%)
  high shelf (block 8): −4dB fixed at 5500Hz
  output L (block 9) → VCA REVERB SEND audio in 1 (block 1)

- Reverb Lite [RESONANCE VERB] — 5 blocks — channels: mono to stereo
  input L (block 1) ← VCA REVERB SEND audio out 1
  decay time (block 3): 1.8s / mix (block 4): 100 (fully wet)
  output L (block 5) → VCA REVERB RETURN audio in 1
  output R (block 6) → P2 Audio Balance audio in1 R (block 2)

- VCA [REVERB SEND] — 3 blocks
  level control (block 3) ← Value [REVERB LVL] (28%)
- VCA [REVERB RETURN] — 3 blocks
  level control (block 3): 75% fixed (not CV — prevents feedback)
  audio out 1 (block 4) → P2 VCA [WET VCA] audio in 1 (block 1)

## Pitch Tracking Note

ZOIA's Pitch Detector outputs V/Oct note value (0 = A4 = 440Hz). Delay Line
delay time is linear (0–1 = 0–100ms). A true V/Oct → 1/frequency conversion
is not natively possible in ZOIA. The Pitch Detector CV is scaled via
connection strength into the Delay Line delay time range, giving approximate
pitch tracking. This is musically equivalent to how analog sympathetic strings
work — resonators bloom on harmonically related notes.

## Build Order (incremental CPU check after each step)

1. P2: Audio Input + Audio Output → verify dry pass-through
2. P3: SV Filter [SOFT LIMITER] + Pitch Detector — test pitch detection
3. P3: Env Follower + Comparator — test gate triggers (watch ZOIA CV display)
4. P4: Delay Line V1 + VCA V1 FEEDBACK — test comb resonance, set feedback to ~60%
5. P4: Delay Line SPREAD L + SPREAD R → SV Filter DAMPENING — test stereo
6. P4: Delay Line V2 + VCA V2 — check CPU (~20%)
7. P4: Delay Line V3 + VCA V3 — check CPU (~24%)
8. P3: Sample and Hold + ADSR + CV Mixer + CV Rectify — wire pitch CV chain
9. P5: Tone Control + Reverb Lite + VCA Send + VCA Return — check CPU (~32%)
10. P2: VCA WET + VCA DRY + Audio Balance — wire mix bus
11. P1: All Value modules + Stompswitches — wire all CV connections (~free)
12. Final: CPU should read ~28–35%. If >40%, reduce FEEDBACK knob first.

*If CPU exceeds 40%: remove Delay V3 + VCA V3 (saves ~2.3%). Then V2 (another ~2.3%).*
